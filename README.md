# Необходимо заполнение следующих констант:
    - Абонентская плата: выбирается из справочника Номенклатура услугой, соответствующей предоставлению клиенту услуги абонентского обслуживания в течение месяца (фиксированная оплата за месяц по договору с типом Абонентское обслуживание), при отсутствии такого элемента в справочнике необходимо его создание.
    - Работы специалиста: выбирается из справочника Номенклатура услугой, соответствующей предоставлению клиенту услуги работ специалиста (почасовая оплата по заявке клиента), при отсутствии такого элемента в справочнике необходимо его создание.
    - ВКМТокенТГБот: токен бота телеграмм для рассылки оповещений специалистам о назначенных работах (требуется заранее создать бота телеграмм).
    - ВКМГруппаТГ: идентификатор группы телеграмм, в которую входят специалисты, которые должны получать оповещения от бота (требуется заранее создать группу и включить в нее сотрудников, которые должны получать оповещения).
# Необходимо заполнение справочника пользователей, с указанием следующих сведений:
    - логин
    - пароль
    - права доступа (выбором соответствующего поставляемого профиля)
    - данные по физическому лицу (заполнить Ф.И.О.)
    - подразделение (Администрация или Специалисты) 
    
# Необходимо заполнение регистра Условия оплаты сотрудников. 
    - процент от выполненных работ для каждого специалиста (процент может бть равен нулю, но запись в регистре должна присутствовать)
    - оклад для каждого сотрудника 
# Необходимо заполнение регистра График работы. 
# Для расчета отпускных требуется заполнение сведений об окладе, проценте выплат и начисленных суммах не менее, чем за предыдущие 12 месяцев от даты начала отпуска сотрудника.
