Эталонная база для проведения тестов находится в каталоге AutoTests в файле TestBase.dt файла. 
Для запуска тестов необходимо создать конфигурацию в 1С, прописать в поле Дополнительные 
параметры запуска ключ /TESTMANAGER, после создания пустой конфигурации запустить ее в 
режиме конфигуратора и загрузить в пустую конфигурацию dt файл. После загрузки конфигурации 
согласиться с перезапуском конфигуратора по запросу 1С, выбрать вход под пользователем Администратор.
После входа в режиме Конфигуратора в меню Администрирование выбрать Пользователи, в открывшемся 
списке выбрать пользователя Администратор и на вкладке Основные снять галку с пункта 
Защита от опасных действий, после чего закрыть конфигуратор. Запустить конфигурацию в режиме 1С Предприятие,
 войти под Администратором, после открытия окна убедиться, что в заголовке присутствует надпись 
 Менеджер тестирования. Затем через меню Сервис и настройки выбрать меню Файл – Открыть 
 и в открывшемся окне найти и выбрать файл vanessa-automation.epf.
